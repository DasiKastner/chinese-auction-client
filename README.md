## מערכת מכירה סינית – צד לקוח (Angular)

מערכת מכירה סינית היא אפליקציית Web לניהול הגרלות (Chinese Auction), המאפשרת למשתמשים לצפות במתנות, להוסיף כרטיסים לעגלה ולבצע רכישות, עם דגש על חוויית משתמש נוחה ואינטראקטיבית.

### תיאור הפרויקט

צד הלקוח בנוי ב־Angular ומספק ממשק משתמש לתקשורת עם ה־API של השרת.
האפליקציה כוללת את הפונקציות הבאות:

- הצגת מתנות – רשימת מתנות עם תמונה, מחיר ותיאור
- הוספה לעגלה – הוספת מתנות (כרטיסים להגרלה)
- ניהול עגלה – צפייה, עדכון כמויות והסרה של פריטים
- חישוב סכום כולל – חישוב אוטומטי של מחיר הרכישה
- ביצוע רכישה – שליחת בקשות לשרת
- זיהוי משתמש – שליפת מזהה משתמש מתוך JWT
- סטטוס הגרלה – חסימת רכישה למתנות שכבר הוגרלו

המערכת מתקשרת עם צד השרת באמצעות קריאות HTTP ומאפשרת עבודה דינמית ועדכנית מול הנתונים.

### מבנה הפרויקט

הפרויקט מבוסס על מבנה סטנדרטי של Angular וכולל:

- components
- services
- models

### פירוט:
- components – קומפוננטות UI (לדוגמה: דף הבית)
- services – שירותים לתקשורת עם השרת:
- CategoryService
 -GiftServiceService
 -DonorService
- CartService
- models – מודלים של הנתונים:
- Gift
- Donor
- Category
- Purchase
זרימת עבודה (Client Flow)
- טעינת מתנות מהשרת בעת כניסה לדף הבית
- הוספת מתנה לעגלה
- שליפת עגלת המשתמש מהשרת
- עדכון כמויות או הסרת פריטים
- חישוב סכום כולל
- ביצוע רכישה עבור כל פריט בעגלה
- טכנולוגיות
- Frontend: Angular
- שפת פיתוח: TypeScript
- UI Library: PrimeNG
- ניהול נתונים: RxJS
- תקשורת עם שרת: HttpClient
- Authentication: JWT (sessionStorage)
### תכונות עיקריות
- תצוגת מתנות במבנה Grid
- הוספה והסרה של פריטים מהעגלה
- עדכון כמות כרטיסים לכל מתנה
- עגלת קניות צדדית (Sidebar)
- חישוב סכום כולל בזמן אמת
- הודעות למשתמש (Toast)
- טיפול בשגיאות מהשרת

## איך להפעיל את הפרויקט
### דרישות מקדימות
- Node.js
- Angular CLI
### שלבים להרצה
#### התקנת חבילות:
```bash
npm install
```
#### הרצת הפרויקט:
```bash
ng serve
```
#### פתיחת הדפדפן בכתובת:
http://localhost:4200
### הערות
- יש לוודא שצד השרת רץ לפני הפעלת צד הלקוח
- האפליקציה תלויה ב־API לצורך שליפת נתונים וביצוע פעולות
- זיהוי המשתמש מתבצע באמצעות Token הנשמר ב־sessionStorage
